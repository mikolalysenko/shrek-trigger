# Puss hatchet equipment variant

All 245 native frames are mapped to generated source pixels. The three saved equipment-variant sheets contain real broad steel hatchets with wooden handles and green insets, generated by editing only the original Puss weapons. No visible rapier is relabelled as a hatchet.

The 64 extracted poses consist of 28 armed hatchet poses and 36 unarmed/story poses sampled from the exact same PNGs and extraction settings as the rapier variant. Native frame counts, timing, source colors and equipment-switch behavior are preserved. The combined graphics bank is measured in ../puss/coverage.draft.json.

Reproduce the active source mapping (`import-spec.json`) with:

```sh
node scripts/import-raster-art.mjs
```

`review-v2.html`, `review-v2-frames.png` and `review-v2.json` provide a fixed source-mapped review. `native-review-v2-6x.png` shows the extracted source poses. Exact prompts and provenance accompany the three hatchet PNGs. The equipment variant is active. All245 native frames, equipment switching and menu aliases pass the native tests; Snes9x and bsnes independently verify both weapon variants on cartridge `510c664a4388139b566519894d3b91918d3f102c609526e69cd97e81aed5ff48`.
